# Seyyar Satış

Seyyar satıcılar için satış, stok, cari (veresiye) ve kasa uygulaması. Telefon ve tabletten çalışır, internet yokken satış kaydeder, Bluetooth fiş yazıcıya yazdırır, e-Arşiv/e-Fatura için UBL-TR XML üretir.

Canlı adres: https://sdurusu1.github.io/seyyar-satis/

- Veriler Supabase veritabanında tutulur (giriş şifreli, yalnızca yetkili kullanıcılar erişir).
- Koddaki Supabase anahtarı tarayıcıda kullanılmak üzere tasarlanmış herkese açık (publishable) anahtardır; verileri satır düzeyi güvenlik kuralları korur.
